## 界面速览

窗口分三块：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 文稿区 | 左侧 | 输入文本，插停顿、插副语言 |
| 参数区 | 右侧 | 选嗓音、调语速音调音量与风格 |
| 顶部语言条 | 最上 | 第一行选语言，第二行选口音 |
| 底部状态栏 | 最下 | 显示运行方式（网页版 / 桌面版）与当前输出格式 |

顶部右侧有四个**输入方式**按钮，决定了左侧文稿区长什么样：

- **单人语音** —— 一整段文本一个人读
- **多人语音** —— 每行一句话，行首标说话人
- **上传文件** —— 传 txt 文件
- **听力测试** —— 按考卷格式生成听力音频

左侧竖排三个入口：**语音合成**（默认）、**语音转文字**（开发中）、**设置**。

## 一、单人语音

最常用的模式，一整段文本由一个人读。

1. **选语言和口音**：顶部第一行选语言（9 种），有多个口音的语言第二行会多出一排口音标签（如 English 下有 US / UK / AU / IN 等 14 个）。这两项决定右侧能选到哪些嗓音。
2. **输入文本**：直接打字或粘贴。右下角显示字数。
3. **（可选）加停顿**：把光标放到要停顿的位置，点右栏「停顿」里的按钮（浮动条上能调时长 0–5 秒）。也可以直接在文本里**手写** `[停顿 2s]`。
4. **（可选）加副语言**：笑声、咳嗽、换气、叹气等，点按钮插入到光标处；同样可以手写 `[laughter]`。
5. **选嗓音**：右栏下拉里挑一副。点旁边的 🔍 可以按名字搜索，点喇叭先试听一句，点 ⭐ 收藏（收藏过的会排在最前并带星标）。
6. **调参数**：语速、音调、音量、风格、风格强度。风格只对英文内容听得出来，中文选了基本没差别。
7. **生成**：点「生成语音」（或按 `Ctrl+Enter`）。过程中可以随时点「停止」。
8. **导出**：生成完可以直接试听，或点导出下载音频文件。

> **标记可以手写，也可以粘贴**：文本里写对格式就等同于插入芯片，粘贴带标记的文本会自动还原成可编辑的芯片（删一个芯片就是删一个标记，不会留下零散方括号）。
>
> | 想加的 | 写法 |
> | --- | --- |
> | 停顿 2 秒 | `[停顿 2s]`、`[2s]` |
> | 停顿 500 毫秒 | `[500ms]`、`[停顿 500]` |
> | 笑声 / 咳嗽 / 清嗓 / 呼吸 / 叹气 / 打哈欠 | `[laughter]`、`[coughing]`、`[throat_clearing]`、`[breathing]`、`[sighing]`、`[yawning]` |
>
> 三点要注意：① 方括号用**半角** `[ ]`，全角 `［ ］` 不认；② 单独的 `[500]` **不算**停顿（写 `[500ms]` 或 `[停顿 500]`），这样 `[1]`、`[2024]` 这类方括号就不会被误当成停顿；③ 认不出的方括号**原样读出来**，不会不发声。

## 二、多人语音

两个人对话，交替朗读。

- **格式**：每行一句话，行首用 `A:` 或 `B:` 指定说话人。**不加前缀的行会自动并入上一句**（方便长句换行写）。
- **两个角色各配一副嗓音**：右栏「对话角色」里 A 和 B 各有一个下拉和一个语速滑块。
- **不用点按钮也行**：行首直接手打 `A:` / `B:` 就好（全半角冒号都认），停顿同样可以直接手写 `[停顿 2s]`。点 A / B 徽标只是帮你插一个说话人芯片。

```
A: 周末你有没有做什么好玩的事？
B: 去了本地的市集，吃了太多小吃。
A: 听起来不错，下次带上我。
```

> **注意**：多人语音模型**只有 2 个槽位**。稿子里出现第三个说话人时，他会自动沿用第二个人的音色，不会报错。这也是「听力测试」要用另一种做法的原因（见下一节）。

## 三、上传文件

把写好的 txt 直接传进来。

- 拖拽文件到虚线框，或点击选择。**上限 5MB / 50000 字符**。
- 勾选「**按多人语音解析**」，就会按上面 `A:` / `B:` 的规则解析成对话，角色和语速在右栏配置。
- 不勾选则整篇当单人文本读。
- txt 里写的 `[停顿 2s]`、`[laughter]` 标记同样生效（格式见第一节末尾的那张表）。

## 四、听力测试

**用途**：把一份听力考卷文稿，生成一条完整可用的听力音频——中文播报、男女对话、英文独白、提示音、涂卡留白全都按顺序拼好。

### 4.1 文稿怎么写

关键规则只有四条：

| 内容 | 怎么写 | 说明 |
| --- | --- | --- |
| **中文播报** | 直接写一行中文 | 用「中文播报」那张卡片的音色朗读 |
| **男声对话** | 行首写 `M:` | 例：`M: Do I need a card to enter the building?` |
| **女声对话** | 行首写 `W:` | 例：`W: Yes. You'll get your card this afternoon.` |
| **英文独白** | 行首写 `M:` 或 `W:`，但**这一段只有这一个人说话** | 自动识别为独白，改用独白音色朗读 |

**独白是怎么判断的**：一段连续的同角色行，如果整段没有出现另一个角色，就当作独白。所以写独白时务必先标明 `M:` 或 `W:`，让程序知道该用哪副嗓子。

**起点从哪里算**：默认从文稿里的「**听力考试正式开始**」这一行开始生成；前面的内容（考场须知之类）会被跳过。如果希望**连开头试音部分一起生成**，勾上「包含开头试音部分」。

**停顿怎么加**：光标放到位置，点右栏「停顿」按钮插入停顿芯片；也可以直接手写 `[停顿 2s]`。留白（如「现在你有 5 秒钟的时间…」之后的空白）都靠这个，程序**不会**去自动解析文本里的时间描述。

> **一个必须知道的写法**：**不要单独把停顿放一行**。停顿芯片要跟在某一句话后面（或并进上一句所在的行），否则它会被当成一个「只有停顿的空块」，整条生成失败，报错是「有一段文稿是空的」。

### 4.2 两种对话方式：选哪个

顶部语言条位置有两个切换标签：**原生模式** / **普通模式**。这是同一段对话的两种合成路线。

| | 原生模式 | 普通模式 |
| --- | --- | --- |
| 原理 | 微软 MultiTalker 多说话人模型，一次请求出整段对话 | 男女各用一副普通音色，一条请求里切换音色 |
| 音色可选范围 | **仅 8 个**说话人（Ada、Ava、Emma、Jane、Andrew、Brian、Davis、Steffan） | **整个英文目录**任选（含 Neural-HD / HD-Omni 等） |
| 听说效果 | 韵律连贯自然，是模型级对话 | 男生读完换女生，接缝处靠句末自然停顿衔接，略有拼接感 |
| 语速 | 有时偏快，调慢会显得拖沓 | 两角色语速**各自独立**，可以一人快一人慢 |
| 口音页签 | 不显示（就那 8 个人） | 显示，14 个英语口音都能挑 |
| 延迟补偿滑块 | 不显示（轮次之间的疏密由 MultiTalker 模型自己决定，没有可插入固定间隔的位置） | 显示 |

**建议**：想要最自然的听感、且 8 个说话人够用 → 原生模式。想挑特定嗓子、或需要男女语速分别微调 → 普通模式。

> 两种方式**各自记住自己的选择**，来回切换不会丢。

### 4.3 四张卡片（音色与语速）

右栏在听力模式下排四张卡，每张卡片各有**一个下拉和一个语速滑块**：

| 卡片 | 管什么 |
| --- | --- |
| **中文播报** | 所有中文行的朗读音色（固定在中文嗓音里选，不受上方口音页签影响） |
| **对话角色 M** | 男声（原生模式选说话人；普通模式选任意英文音色） |
| **对话角色 W** | 女声（同上） |
| **英文独白** | 独白段的音色 |

每张卡片右侧都有喇叭按钮，可以先试听再决定。

**独白音色会自动跟着女声走**：选完 M / W 之后，独白默认变成 W 那一副，省得再选一遍。你**手动改过独白之后**，它就不再自动跟随了（直到你重新载入页面）。

### 4.4 三个开关

文稿区下方：

- **包含开头试音部分** —— 勾上则连「听力考试正式开始」之前的内容一起生成。
- **每段录音开始前插入「叮咚」提示音** —— **默认勾选**。顺序是「叮咚 → 中文提示 → 英文录音」，一道题只响一次（连播两遍时也只响在第一遍之前）。
  > ⚠️ **叮咚只在 MP3 格式下有效**。选 WAV 或 OGG 输出时不会插入提示音（这两种是裸 PCM 字节，混不了 MP3 数据）。
- **结尾留 2 分钟涂卡时间** —— 勾上则在整条音频末尾补 2 分钟静音。

### 4.5 两个间隔

- **两遍间隔**（0–5 秒，默认 1 秒）：一道题连播两遍时，两遍之间留多久。
- **延迟补偿**（0–1000 毫秒，默认 0，**仅普通模式可用**）：男女人声之间的额外停顿。
  > 实测两个音色之间**本来就有约 0.45 秒的自然句末停顿**，所以默认 0 就够。觉得衔接太紧再往上加，加太多会显得拖。

### 4.6 生成

点「生成语音」（或 `Ctrl+Enter`）。程序会：

1. 把文稿按「中文行 / 对话段 / 独白段」拆成若干块；
2. 每块单独合成（几个块同时发，速度快）；
3. 块**末尾**的停顿、两遍间隔、结尾留白走「静音片段」——同长度只合成一次，反复拼接复用；块内与句间的停顿直接写在 SSML 里；
4. 按顺序把所有音频拼成一整条，插入叮咚、补上间隔和结尾留白。

长文会慢一些，进度条会显示状态。生成完可以试听或导出。

## 五、输出设置

左侧「设置」打开输出设置弹窗，两件事：

**输出格式**（三选一，选完即时保存）：

| 容器 | 可用档位 |
| --- | --- |
| **MP3** | 最低 / 低 / 中等（默认）/ 高 / 最高 |
| **WAV** | 低 / 中等 / 最高 |
| **OGG** | 低 / 中等 / 最高 |

默认是 **MP3 中等**（24kHz 96kbps 单声道），也是体积和音质的平衡点。**需要用叮咚提示音就必须选 MP3**。

## 八、常见问题

**生成失败，说「有一段文稿是空的」**
多半是把**停顿芯片单独放了一行**。把它挪到某一句的末尾（或并进上一句那一行）再试。

**生成失败，说「有一段录音是空的，请检查 M: / W: 行」**
某一段对话里所有行都没有实际内容。检查这一段是不是只有 `M:` 后面什么都没写。

**听不到叮咚提示音**
按顺序检查：① 输出格式是 MP3 吗（WAV / OGG 不插）；② 文稿区下方「插入叮咚」有没有勾上。

**停顿没有生效**
先按「停顿插在哪」对号入座（2026-10-07 实测，六类音色逐一验过）：

- **句子中间、两句之间、以及一段对话里两个轮次之间**的停顿：**一律生效**，与音色无关。原生模式也一样生效。
- **落在整条音频最末尾**的停顿：中文普通音色（如晓晓）、英文普通音色（如 Andrew / Ava）生效；**DragonHD 系列（含 Flash / Omni）、MAI 系列、MultiTalker 会被端点吞掉**。这是服务端的裁剪行为，不是写法问题。听力测试里这种位置的停顿（一段录音之后的作答时间）由程序改用「静音片段」在块后拼接，所以照常生效；单人 / 多人模式下若把停顿放在整段文本的最末尾，遇到上面几类音色就会听不到。
- 单独一行的停顿行是无效写法，见上面第一条。
- 手写的标记检查一下写法：单独的 `[500]` 不算停顿，要写 `[500ms]` 或 `[停顿 500]`；方括号必须是半角。

> 顺带一提：微软文档里的 `mstts:silence`（`Tailing-exact` / `Leading-exact` 等）**不能**用来解决上面这条。它是官方元素、本身能用，但**按音色家族分**：普通 Neural 音色（晓晓、AvaNeural）实测生效且精确；HD 家族（DragonHD 系列含 Flash / Omni、MAI、MultiTalker）实测完全不生效。http / https 两种命名空间、叠加型与 `-exact` 绝对型、标签摆在文本前（官方示例的摆法）与摆在文本后，四种写法都不改变这个结果。微软在同一篇文档里也写了「并非所有语音都支持所有 SSML 标记」，HD 语音要另查。

**某个音色的语速明显不正常**
个别新音色（MAI 系列）在部分语速档位下表现异常，换一副嗓子或用原生模式即可。

**网页版报错说分块太多**
网页版跑在 Cloudflare Workers 免费额度上，**单次最多 50 个子请求**。文稿特别长时（块数太多）会超。办法：改用桌面版（上限 100 组），或把文稿拆成两条分别生成。桌面版没有这个限制。

**多人语音里第三个人说话，嗓音不对**
多人语音模型只有 2 个槽位，第三个人会沿用第二个人的嗓子。需要三个以上不同嗓音，只能用听力测试的那种拼法。

## 九、限制与已知表现

| 项目 | 限制 |
| --- | --- |
| 上传 txt | ≤ 5MB、≤ 50000 字符 |
| 单人 / 多人长文本 | 每组 ≤ 1500 字符，最多 40 组（桌面版 100 组） |
| 多人对话槽位 | 只有 2 个，第三人起沿用第二人 |
| 多人对话语言 | 仅英文内容稳定；中文对话请选 `en-Multitalker` |
| 停顿上限 | 单条 `break` / 静音片段上限 20 秒 |
| 叮咚提示音 | 仅 MP3 输出有效 |
| 停顿（句内、句间、轮次之间） | 所有音色都有效 |
| 停顿（落在音频最末尾） | 中文 / 英文**普通**音色有效；DragonHD 系列（含 Flash / Omni）、MAI 系列、MultiTalker 会被端点吞掉。听力测试这类停顿由程序另拼静音，不受影响 |
| 语速 | 对所有音色有效 |
| 风格 / 强度 / 音调 | 对多人对话无效（原生模式） |
| 风格 | 只对英文内容听得出来，中文选了基本没差别 |
| 副语言 | Omni 系列各语言可用；HD 系列中文以外可用；Flash 系列不生效 |
| 合成 | **必须联网**（走微软 Edge TTS 在线服务） |

详细的技术规格与接口用法见 [README](../README.md)。
